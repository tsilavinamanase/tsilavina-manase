# Tsilavina Portfolio V2
Vue 3 + Vite + Tailwind CSS + jQuery.

Features: FR/EN/中文, dark mode persistent, jQuery scroll animations, responsive design, phone + WhatsApp + social links, contact form that sends the entered information through a prefilled WhatsApp message.

## Photo
Place your real photo at `public/profile.jpg`. Until then, the portfolio uses `profile-placeholder.svg` automatically.

## Install
`npm install`
`npm run dev`

## Production
`npm run build`
